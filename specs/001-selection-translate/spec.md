# Feature Specification: 浏览器划词翻译

**Feature Branch**: `001-selection-translate`

**Created**: 2025-06-07

**Status**: Draft

**Input**: User description: "实现一个浏览器划词翻译插件，参考 SENTENWORD 风格：选中文字后下方出现图标，悬停展示 AI 查词弹框"

## Clarifications

### Session 2025-06-07

- Q: 选中「句子」时弹框展示什么？ → A: 自动区分——单词/短语（≤5 词）用词典模式；句子用翻译模式（仅原文+中文译文）
- Q: 选中中文文字时怎么处理？ → A: 照常查词——中文也走 AI 释义（释义、用法、近义词等），不拦截
- Q: 翻译图标什么时候消失？ → A: 查词弹框出现后（含加载态）立即隐藏图标；弹框关闭后不重新显示图标，直至下次新选区
- Q: 插件在哪些页面上生效？ → A: 所有页面（含 chrome://、新标签页、本地 file:// 等），浏览器禁止注入的页面除外
- Q: 相同文字重复查词是否缓存？ → A: 不缓存，每次悬停均重新请求 API
- Q: 查词结果是否流式输出？ → A: 是——API 流式返回，首个字符到达前显示 loading，之后逐字/逐段更新弹框

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 划词悬停查词（核心） (Priority: P1)

用户在浏览网页时选中一个单词或句子，选区下方出现翻译图标；鼠标悬停图标后，弹出卡片展示 AI 结果，无需离开当前页面。系统自动区分模式：选中 ≤5 个词时展示词典详情（音标、词性、例句）；选中完整句子时展示翻译结果（原文 + 中文译文）。

**Why this priority**: 这是产品核心体验，参考目标 UI 的主路径。

**Independent Test**: 在英文文章页选中 "welcome"，悬停图标后 5 秒内看到含音标、词性、例句的弹框。

**Acceptance Scenarios**:

1. **Given** 插件已安装且 API 已配置，**When** 用户选中页面上一段文字，**Then** 选区正下方出现翻译图标，页面原文不被修改
2. **Given** 翻译图标已出现且选区为单词/短语（≤5 词），**When** 用户悬停图标，**Then** 展示词典模式弹框：原词、音标（如有）、主要释义、按词性分组的释义与例句
3. **Given** 翻译图标已出现且选区为句子（>5 词），**When** 用户悬停图标，**Then** 展示翻译模式弹框：原文 + 中文译文（不展示词性拆分）
4. **Given** 用户悬停图标且查词弹框出现（含加载态），**When** 弹框展示，**Then** 翻译图标立即隐藏
5. **Given** 弹框已展示，**When** 用户点击关闭按钮或移开鼠标（离开弹框区域），**Then** 弹框关闭，图标不重新出现（直至下次新选区）
6. **Given** 用户未选中任何文字，**When** 页面无选区，**Then** 不显示翻译图标和弹框
7. **Given** 用户选中中文词语或句子，**When** 悬停图标，**Then** 照常展示 AI 释义（释义、用法说明、近义词/相关表达等），不提示「请选择外文」

---

### User Story 2 - API 密钥配置 (Priority: P2)

用户在插件设置页填入硅基流动 API Key，保存后即可使用 AI 查词；未配置时给出明确引导。

**Why this priority**: 没有有效密钥，核心流程无法运行。

**Independent Test**: 填入有效 API Key 后重新划词，弹框正常展示结果；清空密钥后划词，弹框提示前往设置。

**Acceptance Scenarios**:

1. **Given** 用户打开设置页，**When** 输入硅基流动 API Key 并保存，**Then** 密钥安全存储，设置页不回显完整密钥
2. **Given** 用户未配置 API Key，**When** 悬停翻译图标，**Then** 弹框显示「请先配置 API Key」及跳转设置的入口
3. **Given** API Key 无效或余额不足，**When** 请求查词，**Then** 弹框显示可理解的错误信息，并提供重试

---

### Edge Cases

- 选区靠近视口底部时，弹框自动翻转到上方，不被裁切
- 选区靠近视口左右边缘时，弹框自动偏移，完整保持在可视区域内
- 选中文本过长（>500 字符）时，提示缩小选区，不发起请求
- 选中纯数字/标点/空白时，提示「无可查词内容」
- 选中中文时：词典模式展示拼音（如有）、释义、用法与例句；句子模式展示句意解读或语义说明（仍为中文）
- 快速切换选区时，仅保留最新选区的图标与弹框
- 弹框出现后图标已隐藏，用户仅需与弹框交互，无需再从图标移向弹框
- 网络超时或模型返回异常时，展示错误态并提供重试
- 在输入框内选中文字时，弹框不遮挡光标编辑区域（优先显示在选区上方或侧方）
- 浏览器禁止扩展注入的页面（部分 chrome:// 内部页）上，划词功能不可用，不影响页面本身

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 用户选中文字后，插件 MUST 在选区下方显示翻译触发图标（每次新选区仅显示一次，直至弹框出现）
- **FR-002**: 用户悬停图标时，插件 MUST 展示查词弹框（非点击触发）
- **FR-002a**: 查词弹框出现（含加载态）后，翻译图标 MUST 立即隐藏；弹框关闭后 MUST NOT 重新显示图标，直至用户产生新选区
- **FR-003**: 插件 MUST 按选区自动切换模式：≤5 词为词典模式，>5 词为翻译模式
- **FR-003a**（词典模式）: 外文选区展示音标、词性释义与英/中例句；中文选区展示拼音（如有）、释义、用法、近义词及中文例句
- **FR-003b**（翻译模式）: 外文句子展示原文与中文译文；中文句子展示句意解读或语义说明（中文）
- **FR-003c**: 中文选区 MUST NOT 被拦截，与外文选区使用相同的触发与弹框流程
- **FR-004**: 弹框 MUST 提供关闭按钮；关闭或离开交互区域后弹框消失，页面原文不被替换
- **FR-005**: 弹框 MUST 处理视口边界：靠底翻转、靠边偏移，确保内容可见
- **FR-006**: 插件 MUST 通过硅基流动大模型 API 获取查词结果（用户自备 API Key）
- **FR-007**: 插件 MUST 提供设置页配置 API Key；密钥不得暴露在网页 DOM 中
- **FR-008**: 插件 MUST 仅发送用户选中的文字用于查词，不采集无关页面内容
- **FR-009**: 首个 API 响应字符到达前，弹框 MUST 显示 loading 状态（不得空白等待）
- **FR-013**: 查词结果 MUST 以流式方式呈现：硅基流动 API 开启 stream，弹框内容随数据到达逐步更新，无需等完整响应
- **FR-013a**（翻译模式）: 译文逐字/逐段流式显示
- **FR-013b**（词典模式）: 流式阶段先展示逐步出现的文本预览；流结束后解析为结构化卡片（音标、词性、例句）
- **FR-010**: 插件 MUST 支持 Chrome/Edge（Manifest V3）
- **FR-011**: 插件 MUST 尝试在所有可注入页面生效，包括 http/https、file://、chrome:// 及新标签页；浏览器策略禁止 Content Script 注入的页面上功能静默不可用，不报错崩溃
- **FR-012**: 插件 MUST NOT 缓存查词结果；每次悬停触发均向 API 发起新请求

### 明确不在本版本范围

- 收藏 / 生词本（星标）
- 「专业词典」Tab 及外部词典跳转（Cambridge、Oxford 等）
- 发音播放
- 全页翻译、快捷键翻译
- 目标语言切换（默认译为简体中文）
- 查词结果缓存

### Key Entities

- **查词请求**: 选中文本、请求时间、请求 ID
- **查词结果**: 模式（词典/翻译）、原词/原文、流式缓冲文本、音标（词典模式）、主要释义或译文、词性释义列表（词典模式）、状态（加载/流式中/成功/失败）
- **用户设置**: 硅基流动 API Key（加密存储）、默认模型名称

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 90% 测试用户能在 30 秒内完成「选中 → 悬停图标 → 看到查词结果」
- **SC-002**: 图标出现后，悬停到弹框展示 loading 的响应时间 < 1 秒（不含 API 首 token 耗时）
- **SC-006**: 从悬停到首个字符出现在弹框内，用户感知等待时间明显短于「等完整响应一次性展示」；loading 态在首字符前 100% 可见
- **SC-003**: 在屏幕四边各选词测试，弹框 100% 保持完整可见（可滚动但不被裁切）
- **SC-004**: 未配置 API Key 时，100% 显示引导提示而非空白或崩溃
- **SC-005**: 弹框展示不导致目标网页布局错位或脚本报错

## Assumptions

- 参考 UI 为 SENTENWORD 风格卡片弹框，本版本仅保留「AI 查词」单 Tab
- 外文内容默认译为/释为简体中文；中文内容走 AI 释义（不解译为外文）
- 默认模型使用硅基流动平台上较快的中文友好模型（具体型号在 plan 阶段确定，用户可在设置中修改）
- 用户具备稳定网络；离线查词不在范围内
- iframe 内划词不在本版本范围
- 目标为全页面覆盖；受浏览器安全策略限制的页面除外
- 不缓存查词结果，每次交互均实时请求 API
- 查词使用硅基流动 stream 模式，Background 经 Port 将 chunk 推送给 Content Script
